Entry for make.fun's "Weirdest Job Title: Blind Judge Showdown". `main.py` writes the invented job title to `/output/entry.txt`; the only judgment criterion is whether a house judge model finds the title weirder and funnier than another entrant's.

## Run it

```sh
python3 main.py
```

The program writes `/output/entry.txt` (in the grader's sandbox); it takes no input, no network and no secrets.
